# The Reversible Works Exception

Document: RC-REV-01 · Version: 1 · Corpus: demo-2026-01

## 9.1 Restoration without excavation

A new unprotected garden structure is exempt from the new structure prohibition only if it is freestanding, removable without excavation, leaves the old use intact, creates no frontage wall, and changes no listed canal silhouette. Calling a structure temporary is not enough. Habitat closure still applies.
